Persistance des donnees : exemple de forum (SQL)

Documentation interactive de l'API (Swagger UI) : /api - toutes les routes peuvent y etre testees directement.

Memes routes disponibles sous /forum (PostgreSQL) et /forum-sqlite (SQLite), pour comparer la syntaxe.

  • GET /forum/users - SELECT de base
  • GET /forum/posts/:userId - WHERE
  • GET /forum/posts-with-authors - INNER JOIN
  • GET /forum/posts-without-comments - LEFT JOIN
  • GET /forum/most-active-users - JOIN + GROUP BY + COUNT
  • POST /forum/posts/:postId/comments - INSERT + RETURNING
  • PATCH /forum/posts/:id - UPDATE avec WHERE
  • GET /forum/search/vulnerable?q=... et /forum/search/secure?q=... - injection SQL
  • DELETE /forum/posts/:id - ON DELETE CASCADE

Voir README.md pour les commandes de test.
